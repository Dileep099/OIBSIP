\# Android Calculator App (Task 3)



A simple Android calculator app built during my \*\*Oasis Infobyte\*\* internship (Android App Development track).



\## Features

\- Number buttons (0-9) with a display screen

\- Basic operations: addition, subtraction, multiplication and division

\- Clear (C) button to reset the display

\- Backspace button to delete the last digit

\- Button grid laid out in XML



\## Tech Stack

\- Java

\- XML (layouts)

\- Android Studio



\## What I Learned

\- Designing a responsive button layout with XML

\- Handling button clicks with `OnClickListener`

\- Managing calculator state (current number, operator, result) in Java

\- Testing and debugging on the Android emulator

\## How to Run

1\. Clone this repository.

2\. Open the `AndroidDev-Task3-Calculator` folder in Android Studio.

3\. Let Gradle sync, then run the app on an emulator or a real device.
